# kasugai_public_works
独学、成果物等

## MayaScript
### MultiScreenshot.py
指定したカメラ設定のスクリーンショットを撮る処理です。

## TextureCombined
ディレクトリのパスを指定し、そのディレクトリ内の画像全てを結合する処理です。

## VBA
### 文言変換VBA
変換したテキストをセルに入力し、以下の設定をすると実行時その処理を行う。
* 改行コード(vbCrLf,vbCr,vbLf)を\nに置き換える
* 半角スペース、全角スペースを削除する
* 半角数字を全角数字に
* 全角数字を半角数字に
* 指定の文言を削除する
